# Changelog

## Plugin 0.4.3 / server 0.3.3

- Open local HTML reference pages through the mql5-help link handler.
- Add CHM descriptions for all 559 imported functions, with parameters, returns, and notes.
- Highlight API names, ENUM types, input/sinput variables, macros, and indicators.
- Bundle LSP completion, definitions, references, hover, signatures, and symbols.
- Import function/method signatures, structure fields, context, and enum descriptions from CHM.
- Use value lists instead of Markdown tables in IntelliJ documentation popups.
- Support UTF-16, includes, and unsaved buffers; provide an optional MetaEditor/UTM bridge.
- Include MIT licenses, source notices, portable builds, and CI.
- Limit compatibility to IntelliJ Platform 253; verify newer branches before supporting them.
